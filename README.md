# 🚀 Laboratorio CI/CD con GitHub Actions

Este repositorio contiene un laboratorio paso a paso para aprender **Integración Continua (CI)** y **Despliegue Continuo (CD)** usando **GitHub** y **GitHub Actions**, sin depender de Kubernetes ni contenedores externos.

Incluye:
- Ejemplo de CI (build + test)
- Ejemplo de CD (despliegue automático con GitHub Pages)
- Ejemplo de Release automático (por tags)
